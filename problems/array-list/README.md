## Problem

Implement an array using objects. You should not use arrays at all in this exercise, just objects.
Make a class (or constructor function; something you can call new on) called ArrayList
ArrayList should have the following properties:
length - integer - how many elements in the array
pushh - function - accepts a value and adds in the list and return it
pop - function - removes the last value in the list and returns it
get - function - accepts an index and return the value at that position
delete - function - accepts an index, removes value from list, collapses and returns removed value
